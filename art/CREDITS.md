# Art credits

All sprites in `art/tiles/` come from the **Dungeon Crawl Stone Soup** tile set
(`crawl-ref/source/rltiles` in https://github.com/crawl/crawl), which is released
into the public domain / CC0 (it extends the public-domain RLTiles set).

Run `python3 tools/build_atlas.py` after adding or changing files here to
regenerate `public/assets/atlas.png` and `src/assets/atlas.json`.
